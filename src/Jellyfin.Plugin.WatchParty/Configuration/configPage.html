Watch Party

Let a Discord watch party vote to pause, resume, skip, stop, and pick what plays on one host screen. The bot connects out to Discord from this server, so nothing needs to be exposed to the internet.

Invite the bot to your Discord server

Discord

1. Open discord.com/developers/applications and create (or open) your application.
2. Go to Bot, press Reset Token, copy it and paste it here, then Save.
3. Use the invite link above to add the bot to your server. Slash commands appear within a minute.
Members with this role can use force:true to skip the vote, and can /cancelvote. In Discord, turn on Settings → Advanced → Developer Mode, then right-click the role → Copy Role ID.
Also posts every vote result to a channel. Channel settings → Integrations → Webhooks → Copy Webhook URL.

Host screen

The Jellyfin player you screen-share. Start playing something on it and it appears in this list.

Voting

A vote fails if fewer people than this voted. Yes/no votes pass when yes beats no.

Webhook for other tools (optional)

Leave empty to turn it off. Tools send POST /WatchParty/Command with header X-WatchParty-Secret and a body like {"action":"pause","user":"streamdeck"}.
